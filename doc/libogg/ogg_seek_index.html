Timestamp seeking

declared in "ogg/ogg.h";

Ogg exposes time through the granulepos stored in each page. An ogg_seek_index records the byte offset and granulepos of pages while they are read sequentially. Once an index exists, ogg_seek_index_find() returns the byte offset at which a reader should resume in order to reach a requested granulepos.

libogg does not perform file I/O. The application seeks its own source to the returned offset, resets its ogg_sync_state and continues with ogg_sync_pageout().


typedef struct {
  ogg_int64_t offset;
  ogg_int64_t granulepos;
  long        serialno;
  long        pageno;
} ogg_seekpoint;

typedef struct {
  ogg_seekpoint *points;
  size_t         count;
  size_t         capacity;
} ogg_seek_index;

int  ogg_seek_index_init(ogg_seek_index *idx);
void ogg_seek_index_clear(ogg_seek_index *idx);
int  ogg_seek_index_add_page(ogg_seek_index *idx,

int  ogg_seek_index_add(ogg_seek_index *idx,
                        ogg_int64_t offset,
                        ogg_int64_t granulepos,
                        long serialno,
                        long pageno);

                         long serialno,
                         ogg_int64_t target_granulepos,
                         ogg_seekpoint *point);

Building an index

ogg_seek_index_build() is a convenience for a complete in-memory stream. It scans and CRC-checks pages, skips leading junk and ignores a truncated tail. For streaming or large files, call ogg_seek_index_add_page() for every page returned by ogg_sync_pageout(), passing the absolute byte offset of that page's OggS capture pattern. Offsets must be strictly increasing. ogg_seek_index_add() accepts already-parsed page fields.

Both building functions return 0 on success and -1 on invalid arguments or allocation failure. ogg_seek_index_build() replaces the index atomically; a failed build leaves the old index untouched.

Lookup rules

The index is per logical stream: pass the stream's serial number so that interleaved or chained streams with independent granulepos timelines are not mixed. Ogg requires serial numbers to be unique within one physical bitstream, including all links of a chain. Pages with granulepos -1 are retained for offset validation but do not participate in timestamp comparison.

  • Exact hit: the first page whose granulepos equals the target is returned.
  • Between pages: the last page at or below the target is returned. The next timed page is the one that first passes the target, so the start is at most one timed page early.
  • Before the first timed page: the first physical page of that stream is returned, preserving headers and BOS state.
  • At or after the last timed page: the last timed page is returned.
  • A stream containing no timed pages: its first physical page is returned.
  • Unknown serial or an empty index: 0 is returned and point is untouched. Success returns 1; invalid arguments return -1.

    • The returned offset is always the capture-pattern boundary recorded when the page passed CRC validation. Reading from that offset therefore yields byte-identical pages to a sequential read starting at the same page.

    Example

    ogg_seek_index index;
ogg_seekpoint point;

ogg_seek_index_init(&index);
/* While reading sequentially: */
ogg_seek_index_add_page(&index, page_offset, &og);

if(ogg_seek_index_find(&index, serialno, target_granulepos, &point)==1){
  fseeko(source, (off_t)point.offset, SEEK_SET);
  ogg_sync_reset(&sync);
  /* Feed bytes from the new position and continue ogg_sync_pageout(). */
}

ogg_seek_index_clear(&index);

    Complexity

    Memory is one ogg_seekpoint per page. Insertion is amortised constant time. Lookup is an allocation-free linear scan restricted to the selected serial number; it does not require the index to contain only one stream.
